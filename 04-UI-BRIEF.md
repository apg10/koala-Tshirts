# Stitch UI Brief For Koala

## Product
Koala is a clothing ecommerce focused on t-shirts and casual apparel.

## Experience Goal
Design a real ecommerce, not a marketing landing page.

The UI should feel:
- clean
- modern
- product-first
- practical for shopping
- believable as a small apparel brand with admin tooling

## Storefront Screens
- Home
- Product List
- Product Detail
- Cart
- Checkout
- Order Confirmation
- Login
- Register

## Admin Screens
- Admin Product List
- Admin Product Create/Edit

## Visual Direction
- product photography should lead
- restrained layout, not oversized hero marketing
- strong product cards and detail layouts
- clear add-to-cart and checkout flow
- admin panel should be denser and more utilitarian than storefront

## Design System Direction
- typography: clean sans
- shape: low-to-medium radius
- color palette: neutral base with one brand accent
- storefront and admin should share the same core design language

## Constraints
- do not design fantasy features not supported by the repo
- prioritize screens that map to existing pages
- optimize for implementation by a local worker later
